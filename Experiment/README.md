# Chạy notebook EHO

Từ môi trường đã chạy `python -m pip install -e .`, mở `jupyter notebook` và chọn kernel
Python của cùng môi trường. Mở riêng từng notebook và dùng Run All. QUICK là mặc định.
Xem [thiết kế thực nghiệm](../docs/EXPERIMENTS.md) để chạy FULL và đọc biểu đồ.
Notebook EHO tính toàn bộ số liệu từ core. Các archive tham khảo cũ được lưu cục bộ nếu có.

Mở trực tiếp bốn tệp trong thư mục này để xem bảng và biểu đồ đã lưu.
Ba notebook thực nghiệm lưu kết quả FULL với 25 seed. Book Reproduction dùng các số đã in
trong sách. Khi chạy lại với thiết lập mặc định, Jupyter thay đầu ra trên màn hình bằng kết quả QUICK.
